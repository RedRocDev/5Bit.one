# Biscuit Theme Set

A clean reset of the Theme Designer preset catalogue.

- 40 presets total
- 20 light
- 20 dark
- short names only
- strong, saturated visual identities
- old device-specific preset catalogue removed from the Theme Designer

The individual JSON files use the exact schema from `my_custom_theme.json`.

## Light
Brrr, Chutney, Conker, Bonk, Pickle, Bubbles, Banana, Sonic, Pogo, Splash,
Mojito, Fuzz, Bonbon, Nanna, Zesty, Shrimp, Bento, Kiwi, Chutney, Fizzy.

## Dark
Spicy, Moo, Gonzo, Gloop, Dingus, Bongo, Gravy, Biscuit, Jelly, Bogey,
Snooze, Toast, Plop, Wibble, Beetroot, Boing, Flump, Snot, Noodle, Zap.
