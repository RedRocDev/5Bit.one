# Contributing to 5bit.one

Contributions to the 5bit website are welcome.

## Reporting issues

Use the issue tracker at `https://github.com/RedRocDev/5Bit.one/issues` and include reproduction steps and screenshots where useful.

## Submitting changes

1. Branch from the current development branch.
2. Keep user-facing copy and assets specific to 5bit.
3. Run `npm run lint`, `npm run check`, and `npm run build` before submitting changes.
4. Submit a pull request describing what changed and why.

## Source provenance

Do not relabel third-party binaries, artwork, services, trademarks, or source material as 5bit-owned. Preserve required licence notices and document imported material in `THIRD_PARTY_NOTICES.md`.
